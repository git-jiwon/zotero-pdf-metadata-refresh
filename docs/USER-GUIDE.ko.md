# PDF Metadata Refresh 1.0.0 사용 안내

## 정보 찾기 → 변경 내용 확인 → 적용

Zotero에서 PDF가 첨부된 항목을 선택하고 항목의 오른쪽 클릭 메뉴에서 플러그인을 엽니다. **PDF 정보 찾기**는 현재 작업 목록 전체를 확인해 변경안을 만듭니다. 찾기만으로 Zotero의 서지정보가 바뀌지는 않습니다.

항목을 누르거나 **변경 내용 확인**을 눌러 기존 값과 제안 값을 비교합니다. 적용할 항목과 개별 필드를 체크한 뒤 **선택한 정보 적용**을 누릅니다. 확인창의 변경·추가·비우기 내역을 검토하세요.

항목의 **선택** 체크는 작업 대상을 고르고, 필드 체크는 실제로 쓸 값을 고릅니다. **표시** 체크는 나중에 다시 볼 메모입니다. 각각 별개의 결정이며, 항목을 선택해도 쓸 변경이 없으면 적용되지 않습니다.

검색어·필터·페이지를 바꿔도 선택은 유지됩니다. 적용은 현재 보기에서 숨은 선택도 포함할 수 있습니다. 선택 요약에 다른 보기에 포함된 개수까지 나타나므로 적용 범위를 확인하세요.

## 찾기 방법 및 설정

기존 인식 파이프라인의 순서에 따라 다음 경로를 사용합니다.

1. Zotero 기본 PDF 인식, PDF에 인쇄된 DOI·ISBN 등의 식별자 조회
2. 웹사이트와 서지 목록 검색
3. 선택적인 로컬 LM Studio 비전 모델의 페이지 이미지 판독과 필요한 후속 조회

**찾기 방법 및 설정**에서 사용할 경로를 선택합니다. 이미지 판독에는 LM Studio, 이미지를 읽는 비전 모델과 실행 중인 로컬 서버가 필요합니다. 모델의 **사용 안 함**을 선택하면 이미지 판독을 끕니다. 이 기능의 PDF 페이지 이미지 생성은 현재 Windows에서 지원합니다.

덮어쓰기 설정에서는 새 결과에 없는 기존 필드나 저자를 비우는 제안이 생길 수 있습니다. 적용 전에 비교 화면에서 확인하세요. 설정을 바꾸면 그 뒤에 읽는 항목부터 반영되고, 이미 읽은 변경안은 당시의 설정을 유지합니다.

## 근거와 색 읽기

상세 분류와 항목의 근거에 같은 색을 사용합니다.

- 회색: 대기·중단·제외 상태
- 빨강: 처리 오류·파일 없음·PDF 읽기 문제
- 주황: PDF 판독·자료 보완·첨부 선택 등 직접 확인이 필요함
- 노랑: 서지 목록·웹페이지 결과의 추가 확인
- 파랑: 재검색 등 작업 기록
- 초록: 식별 근거 또는 실제 적용 완료

색은 검토 순서를 돕는 정보입니다. 모든 필드의 정확도나 적용 승인을 보장하지 않습니다. 항목을 눌러 개별 값을 비교하세요.

**근거** 열을 누르면 같은 태그끼리 정렬됩니다. 다시 누르면 역순, 세 번째 누르면 작업 순서로 돌아갑니다. 제목 검색은 기존 제목과 새로 찾은 제목을 함께 찾습니다. 보기 초기화로 필터와 검색어를 지울 수 있습니다.

## 멈추기·이어보기·되돌리기

**작업 멈추기**를 누르면 중지를 요청합니다. 진행 중인 저장이나 쓰기는 안전하게 마치고 끝냅니다. 중지 메시지에 나타난 동작으로 남은 작업을 이어가세요. 찾기·적용·복원은 이어서 처리하는 대상이 서로 다릅니다.

고급 작업 도구의 **지난 작업 이어보기**로 저장된 목록을 불러옵니다. 판독 근거가 남은 결과는 현재 정책으로 다시 판정하며, 그 근거가 없는 옛 결과는 저장된 판정을 유지합니다.

**적용 되돌리기**는 선택한 적용 항목을 복원하고, 선택한 적용 항목이 없으면 이 작업에서 적용한 항목 모두를 대상으로 합니다. 적용 뒤 Zotero에서 수동 편집된 항목은 건너뛰어 이후 편집을 보호합니다. 복구가 필요하면 저장된 작업과 백업을 보관하세요.

## 나중에 볼 항목 저장

다시 볼 항목에 표시를 남기고 작업 도구에서 내보낼 수 있습니다. 보고서에는 제목·근거·추출 글·항목 키·파일 정보 등이 포함될 수 있으므로 공유 전에 확인하세요. 표시는 필드 승인이나 적용 허가가 아닙니다.

## 언어와 저장 위치

Zotero의 앱 언어가 한국어이면 한국어 UI, 그 외 언어이면 영어 UI를 사용합니다. 언어를 바꾼 뒤 플러그인 창을 다시 여세요. 서지 값·문서 제목·자료의 글·모델 이름은 원문을 유지합니다.

작업·인식 캐시·이미지 판독 기록과 되돌리기 자료는 Zotero 데이터 폴더 아래에 저장됩니다. [개인정보 안내](PRIVACY.md)와 [보안 안내](../SECURITY.md)를 확인하세요.
